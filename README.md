# 施工日志微信小程序

## 项目简介

施工日志微信小程序是一款专为施工管理人员、监理和建筑工人设计的工具类小程序。通过数字化、规范化的方式，让施工日志的撰写、管理和分享变得更加便捷高效。

## 核心功能

### 1. 微信一键登录
- 基于微信云开发的免注册登录
- 自动获取用户信息
- 邀请码裂变机制

### 2. 施工日志模板化填写
- 标准化的日志模板
- 支持多种工程类型（土建、装修、安装等）
- 自定义模板功能

### 3. 现场拍照上传
- 支持多图上传（最多9张）
- 图片压缩优化
- 云存储管理

### 4. 天气自动获取
- 基于位置的天气信息
- 自动填充到日志中
- 支持手动刷新

### 5. 日志历史查看
- 按日期筛选
- 按项目名称搜索
- 草稿箱管理

### 6. 分享功能
- 分享给微信好友
- 分享到朋友圈
- 生成分享卡片

## 技术架构

### 前端技术栈

## 快速开始

### 1. 环境准备
- 安装微信开发者工具
- 注册微信小程序账号
- 开通云开发服务

### 2. 项目配置
1. 在 `app.js` 中替换 `env` 为你的云开发环境ID
2. 在 `project.config.json` 中替换 `appid` 为你的小程序AppID
3. 在 `cloudfunctions/getWeather/index.js` 中替换 `WEATHER_API_KEY` 为你的和风天气API Key

### 3. 云函数部署
1. 在微信开发者工具中，右键点击每个云函数文件夹
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 4. 数据库初始化
在云开发控制台中，创建以下集合：
- `users` - 用户表
- `logs` - 施工日志表
- `login_logs` - 登录日志表
- `shares` - 分享记录表
- `rewards` - 奖励记录表

### 5. 编译运行
1. 在微信开发者工具中点击"编译"
2. 预览效果
3. 使用真实手机扫码体验

## 常见问题

### Q: 如何获取和风天气API Key？
A: 访问 [和风天气官网](https://dev.qweather.com/) 注册账号并申请免费API Key。

### Q: 云函数部署失败怎么办？
A: 检查Node.js版本、网络连接，或尝试在本地安装依赖后上传。

### Q: 图片上传失败？
A: 检查云存储权限配置，确保已开启相应的存储权限。
