## 2026-07-04 00:22 - 多选批量操作 UI 修复 + 导出格式选择

### 问题与修复
1. **checkbox 无 ✓ 标记**
   - 根因：云数据库 `_id` 是 ObjectId 对象，WXML 中 indexOf 永远匹配不上
   - 修复：加载数据时给每条 log 加 `__id`（字符串版ID）+ `__selected`（布尔状态），WXML 用 `item.__selected` 判断，toggleSelect/toggleSelectAll 同步更新

2. **底部栏遮挡日志 / 按钮出屏幕**
   - 根因：multi-bar 的 bottom 值不够大、按钮用 `<button>` 组件有默认 min-width
   - 修复：bottom 改为 calc(120rpx + safe-area)，容器留白 300rpx；导出/删除按钮改用 `<view>` 绕过 button 默认样式

3. **卡片内容变形**（天气/图片居中）
   - 根因：`.log-content` 在 flex 容器中未设 flex:1
   - 修复：加 `.log-card.multi-mode .log-content { flex:1; min-width:0; }`

4. **批量导出增加格式选择**
   - 点击"导出"→ 弹窗选择 Excel 或 Word → 调用对应云函数
   - 新增 data 字段 showBatchFormat、方法 showBatchFormatPicker/hideBatchFormatPicker/doBatchExport
   - batchExport 改名为 doBatchExport（接受 format 参数）

### 关键技术点
- 微信小程序 `<button>` 组件默认 min-width:104rpx，小按钮场景应改用 `<view>`
- 云数据库返回的 `_id` 是 ObjectId 类型，传 WXML 需转字符串
- 多选选中状态用数据字段 `__selected` 比 indexOf 更可靠
