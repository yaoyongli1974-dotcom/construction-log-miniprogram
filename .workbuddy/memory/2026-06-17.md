## 继续修复与功能完善（09:00-09:31）

### 修复1：发布后返回列表页
- **问题**：从 TabBar 直接打开新建页面，发布后停留在新建页面不返回
- **原因**：`wx.navigateBack()` 无法返回（页面栈只有1层）
- **修复**：修改 `create.js` 的 `saveLog()` 方法，根据页面栈长度判断：
  - 页面栈 > 1 → `wx.navigateBack()`（从其他页面跳转过来的）
  - 页面栈 = 1 → `wx.switchTab()`（从 TabBar 直接打开的）
- **修改文件**：`miniprogram/pages/create/create.js`

### 修复2：发布后列表不刷新
- **问题**：发布日志后，列表页没有及时显示最新内容，必须点搜索才刷新
- **原因**：`needRefresh` 标记没有正确传递到首页
- **修复方案**：
  1. `app.js` → 在 `globalData` 中初始化 `needRefresh: false`
  2. `create.js` → 保存成功后设置 `app.globalData.needRefresh = true`
  3. `index.js` → 在 `onShow()` 中检查 `app.globalData.needRefresh`，如果需要刷新则重新加载列表
- **修改文件**：
  - `miniprogram/app.js`
  - `miniprogram/pages/create/create.js`
  - `miniprogram/pages/index/index.js`

### 修复3：浮动+号按钮无法进入新建页面
- **问题**：日志列表页面的浮动+号按钮点击后没有反应
- **原因**：`index.js` 中使用 `wx.navigateTo()` 跳转，但「新建」页面是 TabBar 页面，必须用 `wx.switchTab()`
- **修复**：`index.js` 的 `createNewLog()` 方法改为使用 `wx.switchTab()`
- **修改文件**：`miniprogram/pages/index/index.js`

### 修复4：浮动按钮位置调整
- **问题**：浮动按钮位置不合适
- **修复**：`bottom: 200rpx` → `bottom: 180rpx`（提高一些，避免被 TabBar 遮挡）
- **修改文件**：`miniprogram/pages/index/index.wxss`

### 功能1：项目名称记忆功能
- **需求**：第一次输入项目名称后，以后自动填充，需要时可以直接修改
- **实现方案**：
  1. 使用 `wx.getStorageSync('lastProjectName')` 读取上次的项目名称
  2. 在 `initPage()` 中自动填充到输入框
  3. 保存日志时，使用 `wx.setStorageSync('lastProjectName', ...)` 记住项目名称
- **修改文件**：`miniprogram/pages/create/create.js`

### 修复5：发布后表单不清空
- **问题**：发布日志后，再次点击进入新建页面，上次发布的内容还在上面
- **原因**：`initPage()` 只重置了日期和项目名称，没有清空其他表单字段
- **修复方案**：
  1. 重写 `initPage()` 方法，完整重置所有表单字段
  2. 在 `app.globalData` 中添加 `needResetCreatePage: false` 标记
  3. 保存成功后设置 `app.globalData.needResetCreatePage = true`
  4. 在 `onShow()` 中检查标记，如果需要重置则调用 `initPage()`
- **修改文件**：
  - `miniprogram/app.js`
  - `miniprogram/pages/create/create.js`

### 功能2：历史记录自动补全功能
- **需求**：施工中很多工序是重复的，点击输入框时显示历史记录，点击即可自动填充
- **实现方案**：
  1. 为每个输入字段添加「📋 历史」按钮（label 右侧）
  2. 点击按钮时，先收起键盘（`wx.hideKeyboard()`）
  3. 延迟 100ms 后，在屏幕中央弹出历史记录面板（遮罩层 + 居中弹出）
  4. 从历史记录中选择后，自动填充到输入框
  5. 保存日志时，自动保存本次输入内容为历史记录（最多保留10条，自动去重）
  6. 支持删除不需要的历史记录
- **修改文件**：
  - `miniprogram/pages/create/create.wxml` → 添加历史按钮和历史面板
  - `miniprogram/pages/create/create.wxss` → 添加历史面板样式
  - `miniprogram/pages/create/create.js` → 添加历史记录逻辑
- **支持历史记录的字段**：
  - 施工内容
  - 施工人数
  - 机械台数
  - 进度百分比
  - 质量检查
  - 安全检查
  - 存在问题
  - 明日计划

### 修复6：历史面板显示位置优化
- **问题1**：历史记录被输入法框挡住 → 改为在点击位置附近弹出
