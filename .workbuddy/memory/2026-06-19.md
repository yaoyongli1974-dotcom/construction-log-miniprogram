# 2026-06-19 工作日志

## 语音输入光标位置插入功能（已解决 ✅）

### 问题
语音识别结果总是插入到文本末尾/行尾，而不是用户光标所在位置。

### 经多轮验证的方案对比（重要经验）
| 方案 | 结果 | 原因 |
|------|------|------|
| setData 绑定 cursorPositions | ❌ | setData 异步延迟，数据过期 |
| 实例变量 + onSelectionChange | ❌ | selectionChange 不够实时 |
| SelectorQuery.context() 读 selectionStart | ❌ | context API 不支持读取，只能设置 |
| catchtouchstart 冻结 | ❌ | catch 阻止冒泡 → 按钮点不了 |
| bindtouchstart 冻结 | ❌ | _cursorPositions 可能是旧值 |
| **onTextareaBlur + e.detail.cursor** | **✅** | blur 在 tap 前触发，cursor 是真实值 |

### 最终有效方案
- 给 5 个 textarea 添加 `bindblur="onTextareaBlur"` 和 `bindfocus="onTextareaFocus"`
- `onTextareaBlur(e)` 中用 `e.detail.cursor` 存入 `this._cursorPositions[field]`
- `onSelectionChange` 作为辅助实时跟踪
- `insertVoiceText()` 读 `this._cursorPositions[field]` 做 substring 拼接插入

### 改动文件
- `miniprogram/pages/create/create.wxml`：5 个 textarea 加 bindblur/bindfocus；去掉语音按钮的 bindtouchstart
- `miniprogram/pages/create/create.js`：
  - 新增 `onTextareaBlur()`, `onTextareaFocus()` 方法
  - 删除 `captureCursorForVoice()` 方法
  - 重构 `insertVoiceText()` 使用 _cursorPositions[field]

✅ 已解决并通过用户实测验证
