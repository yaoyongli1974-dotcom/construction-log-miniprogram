## 🚀 快速提交指南

### 第一步：上传代码
1. 在微信开发者工具中，点击 **上传**
2. 填写版本号：`1.0.0`
3. 填写更新说明（见 `审核提交信息.md` 中的模板）
4. 点击 **上传**

### 第二步：填写审核信息
登录【微信公众平台】→【版本管理】→【提交审核】

#### 必填项：
1. **小程序名称**：施工日志
2. **小程序简介**：施工日志小程序，让工程管理更简单！快速记录施工内容、上传现场照片、自动获取天气，提升工作效率。
3. **服务类目**：生活服务 - 工具（无需特殊资质）
4. **标签**：施工日志、工程管理、建筑工具、现场记录、工作效率
5. **隐私政策**：复制 `隐私保护指引.md` 的内容填写
6. **测试说明**：复制 `审核提交信息.md` 中的测试说明模板

#### 上传截图（2-5张）：
- 首页（日志列表）
- 新建日志页
- 日志详情页
- 个人中心页

### 第三步：提交审核
确认所有信息填写完整后，点击 **提交审核**。

**预计审核时间**：1-3天

## 🔧 常见问题快速参考

### 问题1：审核被拒怎么办？
→ 查看 `审核常见问题及应对方案.md`，根据拒绝原因对应修复。

### 问题2：需要提供资质吗？
→ 当前选择"生活服务 - 工具"类目，**通常无需特殊资质**。
→ 如选择其他类目，需提供对应资质（如营业执照等）。

### 问题3：测试账号怎么提供？
→ 本小程序使用微信一键登录，**无需注册**，审核说明中写明：
```
测试说明：
1. 点击"微信一键登录"即可使用
2. 所有功能均可直接测试
3. 无需特殊权限或注册
```

### 问题4：截图怎么准备？
1. 在微信开发者工具中，点击 **预览**
2. 用手机扫描二维码，打开小程序
3. 截图主要功能页面（每张截图需清晰展示功能）
4. 在公众平台提交审核时，上传2-5张截图
