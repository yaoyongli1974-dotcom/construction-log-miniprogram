## 六、提交流程

### 6.1 在微信开发者工具中
1. [ ] 点击**上传**按钮
2. [ ] 填写**版本号**：1.0.0
3. [ ] 填写**更新说明**（见 `审核提交信息.md`）
4. [ ] 点击**上传**

### 6.2 在微信公众平台中
1. [ ] 登录【微信公众平台】
2. [ ] 进入【版本管理】
3. [ ] 找到刚上传的版本，点击**提交审核**
4. [ ] 填写**审核信息**（见步骤四）
5. [ ] 上传**截图**（见步骤三）
6. [ ] 点击**提交审核**

---

## 七、提交后

### 7.1 跟踪审核进度
- [ ] 在【微信公众平台 - 版本管理】中查看审核状态
- [ ] 通常1-3天出结果

### 7.2 审核通过
- [ ] 点击**发布**按钮上线
- [ ] 可选择灰度发布或全量发布

### 7.3 审核被拒绝
- [ ] 查看**拒绝原因**
- [ ] 根据拒绝原因修复问题
- [ ] 重新提交审核（见 `审核常见问题及应对方案.md`）
