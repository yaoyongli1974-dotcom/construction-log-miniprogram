# 施工日志小程序 - 审核演示视频录制步骤（超详细版）

> 本文档是「审核演示视频脚本.md」的细化补充，提供每一步的具体操作指导。
> 预计总时长：**50~60秒**，刚好符合微信审核要求。

---

## 📋 录制前准备清单

### 1. 测试数据准备（必须提前做完）

打开微信开发者工具 → 真机调试 → 手机微信打开小程序：

```
步骤A：创建第一条测试日志
1. 点右下角「+」按钮
2. 填写内容：
   项目名称：高科智慧园二期智能化项目
   日期：2026-06-21
   天气：晴
   施工内容：今日完成3号楼基础浇筑，投入施工人员15人，主要机械：挖掘机2台，混凝土泵车1台。
   施工人数：15
   进度百分比：35
   质量检查：混凝土强度符合设计要求，钢筋绑扎验收合格。
   安全检查：施工现场安全防护措施到位，无安全隐患。
   存在问题：暂无
   明日计划：继续3号楼基础施工，预计完成基础浇筑。
3. 点「+ 添加照片」→ 选1张测试图片（可选）
4. 点「发布日志」→ 确认返回首页，新日志出现在列表

步骤B：创建第二条测试日志（可选，让列表更丰富）
1. 重复上述步骤，填写不同的项目信息
2. 日期选不同的日子

步骤C：确认首页有数据
- 回到首页，确认能看到至少1~2条日志卡片
- 每条卡片能看到：日期、天气、项目名称、进度%、人数
```

### 2. 手机录制设置

| 设置项 | 安卓手机 | 苹果手机 |
|--------|----------|----------|
| 录屏开启方式 | 下拉通知栏 → 点「屏幕录制」图标 | 设置 → 控制中心 → 添加「屏幕录制」→ 控制中心点录屏按钮 |
| 录制画质 | 设置 → 屏幕录制 → 分辨率选 **1080P** | 设置 → 相机 → 录制视频 → 选 **1080P** |
| 静音 | 音量键调至静音（防止通知声干扰） | 静音开关打开 |
| 勿扰模式 | 开启（防止来电中断录制） | 开启（防止来电中断录制） |

### 3. 微信开发者工具设置（用于真机调试）

```
1. 打开微信开发者工具
2. 点顶部「真机调试」按钮
3. 用手机微信扫描弹出的二维码
4. 手机微信打开小程序后，确认能正常显示数据
5. 保持手机不锁屏（设置 → 显示 → 自动锁屏 → 永不）
```

## 🎬 逐步骤录制脚本（总时间：50~60秒）

> **重要**：每一步操作完后，停留 **1~2秒** 再执行下一步，让审核员看清界面变化。

---

### 镜头1：打开小程序 + 首页展示（**0~6秒**）

| 时间 | 操作 | 画面内容 | 注意事项 |
|------|------|----------|----------|
| 0~1秒 | 手机微信 → 发现 → 小程序 → 搜索「施工日志」→ 点开 | 展示微信打开小程序的过程 | 如果小程序在「最近使用」里，可以直接点开，不用搜索 |
| 1~3秒 | 小程序加载完成，显示首页日志列表 | 能看到至少1条日志卡片，卡片上有日期、项目名称、进度%、人数 | 确保首页有数据，不要出现「暂无施工日志」的空状态 |
| 3~6秒 | 手指**缓慢上滑**一次，展示列表可以滚动 | 列表滚动，展示多条日志（如果有的话） | 滑动速度要慢，让审核员看清每条日志的内容 |

**解说词**（如果使用配音）：
> "这是施工日志小程序，用于施工现场的日常日志记录和管理。首页展示历史日志列表。"

### 镜头2：查看日志详情（**6~14秒**）

| 时间 | 操作 | 画面内容 | 注意事项 |
|------|------|----------|----------|
| 6~7秒 | 点一条日志卡片 | 进入详情页，显示完整日志信息 | 点击位置要在卡片范围内（不要点到按钮） |
| 7~10秒 | **缓慢上滑**查看详情页全部内容 | 展示：日期、状态、项目名称、天气、施工内容、人员进度、质量安全、问题计划、现场照片（如果有） | 确保所有字段都有内容，不要有空白 |
| 10~14秒 | 点「←」返回按钮（或手机自带返回键） | 返回首页，列表依然显示 | 确认返回正常，不要出现空白页 |

**解说词**（如果使用配音）：
> "点击日志可以查看详细信息，包括施工内容、人员情况、质量安全记录等。"

### 镜头3：新建日志（**14~30秒**）⭐ 核心功能，最重要！

| 时间 | 操作 | 画面内容 | 注意事项 |
|------|------|----------|----------|
| 14~15秒 | 点首页右下角的「+」按钮 | 进入新建日志页面 | 「+」按钮在右下角，是一个圆形浮动按钮 |
| 15~17秒 | 点「日期」右边的日期选择器 | 弹出日期选择，选一个日期，确认 | 日期选择器是微信原生picker，样子很清楚 |
| 17~18秒 | 点「天气」右边的下拉框 | 展开天气选项（晴、阴、雨、雪等），选「晴」 | 下拉框会展开一个列表，选完后自动收起 |
| 18~20秒 | 点「项目名称」输入框，输入「高科智慧园」 | 键盘弹出，输入文字，然后点「完成」收起键盘 | 输入速度适中，让审核员看清输入框的变化 |
| 20~22秒 | 点「施工内容」输入框，输入几行文字 | 键盘弹出，输入：「今日完成基础浇筑，投入施工人员15人」 | 输入2~3行即可，不用太多 |
| 22~24秒 | 点「施工人数」输入框，输入「15」 | 数字键盘弹出，输入15 | 数字键盘很清楚 |
| 24~25秒 | 点「进度」输入框，输入「35」 | 数字键盘弹出，输入35 | —— |
| 25~27秒 | 点「质量检查」输入框，输入「混凝土强度符合要求」 | 键盘弹出，输入文字 | —— |
| 27~28秒 | 点「安全检查」输入框，输入「安全防护到位」 | 键盘弹出，输入文字 | —— |
| 28~30秒 | 点底部「发布日志」按钮 | 显示「发布成功」提示，自动返回首页 | 「发布日志」按钮在页面最底部，蓝色背景 |

**解说词**（如果使用配音）：
> "用户可以快速新建施工日志，填写项目信息、施工内容、人员情况等，支持选择日期、天气和位置信息。填写完成后点发布，日志创建成功。"

**操作要点**：
- ✅ 每个输入框点完后，停留 **0.5秒** 再点下一个（让审核员看清）
- ✅ 键盘弹出后，点「完成」或键盘上的「收起」按钮收起键盘
- ✅ 点「发布日志」后，要等到返回首页、看到新日志出现在列表，再继续下一步

## 🎥 录制技巧（非常重要！）

### 1. 手势操作要慢、要稳

| 操作 | 错误示范 ❌ | 正确示范 ✅ |
|------|---------------|---------------|
| 点击按钮 | 飞快点，审核员看不清点了哪里 | 手指在按钮上**停留0.5秒**再抬起 |
| 滑动页面 | 快速一划到底 | **缓慢滑动**，让内容逐行显示 |
| 输入文字 | 用语音输入或粘贴（显得假） | **手动输入**（哪怕慢一点，显得真实） |
| 等待加载 | 不耐烦地重复点 | **耐心等待**，让加载动画完整展示 |

### 2. 避免录制到这些内容

- ❌ 报错弹窗（提前测试确保无Bug）
- ❌ 空白页面（提前准备好数据）
- ❌ 个人真实信息（姓名、电话、精确定位地址）
- ❌ 其他小程序/App的界面（专注展示自己的小程序）
- ❌ 微信通知栏（开启勿扰模式）
- ❌ 低电量提示（提前充电）

### 3. 如果操作失误了怎么办？

- **小失误**（点错按钮、输入错误）：不要停，继续录，后期剪辑可以剪掉
- **大失误**（出现报错、页面崩溃）：停止录制，重新来过
- **建议**：先完整录2~3遍，然后选最好的一遍用于提交

## ✂️ 剪辑指南（可选）

### 推荐剪辑工具

| 平台 | 推荐工具 | 特点 |
|------|----------|------|
| Windows | **剪映电脑版**（免费） | 简单易用，自带配音功能 |
| Mac | **iMovie**（免费）/ **Final Cut Pro** | 苹果自带，流畅 |
| 手机 | **剪映手机版** / **必剪** | 随时随地能剪 |

### 剪辑步骤

```
1. 把手机录制的视频传到电脑（用数据线或微信文件传输助手）
2. 打开剪映 → 导入视频
3. 删除多余部分：
   - 开头的「准备阶段」（比如找小程序的过程，太啰嗦）
   - 中间的「等待时间」（比如键盘弹出后的等待）
   - 结尾的「录制结束后的多余画面」
4. 总时长控制在 45~60秒
5. （可选）加上背景音乐（音量调低至10%~20%，不要盖过解说）
6. （可选）加上解说配音（用剪映的「文本朗读」功能，选「新闻男声」或「专业配音」）
7. 导出：分辨率1080P，帧率30fps，格式MP4
```
