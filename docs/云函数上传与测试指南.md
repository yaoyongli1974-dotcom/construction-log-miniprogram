### 方法1：在微信开发者工具中上传（推荐）

1. **打开微信开发者工具**
2. **进入云开发环境**
   - 点击左侧工具栏的「云开发」图标
   - 确保已开通云开发并选择正确环境（`cloud1-d3gnw41wh36ebbd00`）

## 五、常见问题与解决方法

### Q1: 云函数上传失败

**可能原因**：
1. 网络问题
2. 云函数代码语法错误
3. 云函数依赖安装失败

**解决方法**：
1. 检查网络连接
2. 在本地编辑器中检查云函数代码语法
3. 在云函数目录中手动运行 `npm install`
4. 查看微信开发者工具的控制台错误信息

### Q2: 云函数调用失败

**错误信息**：`cloud.callFunction:fail Error: 函数不存在`

**解决方法**：
1. 确认云函数已上传到云端
2. 确认云函数名称拼写正确（区分大小写）
3. 在云开发控制台中查看云函数列表

### Q3: 云函数超时

**错误信息**：`cloud.callFunction:fail Error: 函数执行超时`

**解决方法**：
1. 检查云函数代码中是否有无限循环
2. 增加云函数超时时间（在云开发控制台中配置）
3. 优化云函数代码，减少数据库查询次数

### Q4: 数据库权限错误

**错误信息**：`permission denied`

**解决方法**：
1. 检查数据库集合的权限配置
2. 确认用户已登录（能正确获取OpenID）
3. 在云函数中使用管理员权限操作数据库（云函数默认有管理员权限）

## 六、调试技巧

### 1. 查看云函数日志

在云开发控制台的「日志」中，可以查看云函数的执行日志：

1. 进入云开发控制台
2. 点击「日志」
3. 选择要查看的云函数
4. 查看调用日志和错误信息

### 2. 在云函数中打印日志

在云函数代码中，使用 `console.log()` 打印日志：

```javascript
// cloudfunctions/createLog/index.js
exports.main = async (event, context) => {
  console.log('收到请求', event);
  
  try {
    // 业务逻辑
    const result = await db.collection('logs').add({ ... });
    console.log('创建成功', result);
    
    return { success: true, logId: result._id };
  } catch (err) {
    console.error('创建失败', err);
    return { success: false, message: err.message };
  }
};
```

### 3. 在小程序端捕获错误

在小程序端调用云函数时，使用 `try-catch` 捕获错误：

```javascript
// miniprogram/pages/create/create.js
async saveLog() {
  try {
    const result = await wx.cloud.callFunction({
      name: 'createLog',
      data: { logData: this.data.log }
    });
    
    if (result.result.success) {
      wx.showToast({ title: '保存成功', icon: 'success' });
    } else {
      wx.showToast({ title: result.result.message, icon: 'none' });
    }
  } catch (err) {
    console.error('调用云函数失败', err);
    wx.showToast({ title: '保存失败', icon: 'none' });
  }
}
```

## 七、性能优化建议

### 1. 数据库查询优化

- **使用索引**：为常用查询字段创建索引
- **限制返回字段**：只查询需要的字段
- **分页查询**：避免一次查询过多数据

```javascript
// 优化前
const result = await db.collection('logs').get();

// 优化后
const result = await db.collection('logs')
  .field({ date: true, projectName: true, status: true }) // 只返回需要的字段
  .skip((page-1) * pageSize)
  .limit(pageSize)
  .get();
```

### 2. 云函数冷启动优化

- **减少依赖**：只安装必要的npm包
- **使用全局变量缓存**：避免重复初始化
- **设置合适的超时时间**

```javascript
// 在云函数外部初始化（利用冷启动缓存）
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database(); // 全局变量，下次调用可复用

exports.main = async (event, context) => {
  // 直接使用 db，无需重新初始化
  const result = await db.collection('logs').get();
  return result;
};
```
