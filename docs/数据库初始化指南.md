## 二、数据库权限配置

### 在云开发控制台配置集合权限：

#### users 集合权限
```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

#### logs 集合权限
```json
{
  "read": "doc.userId == auth.openid",
  "write": "doc.userId == auth.openid"
}
```

#### login_logs 集合权限
```json
{
  "read": "auth.openid == 'admin'",
  "write": true
}
```

## 三、创建集合步骤

### 方法1：在云开发控制台手动创建
1. 打开微信开发者工具
2. 点击左侧「云开发」图标
3. 在云开发控制台中，点击「数据库」
4. 点击「+」号创建集合
5. 输入集合名称：`users`、`logs`、`login_logs`
6. 为每个集合设置权限

### 方法2：使用云函数初始化（推荐）
创建一个初始化云函数：


## 四、需要的索引

### logs 集合索引
| 索引字段 | 排序方式 | 索引类型 | 说明 |
|---------|---------|---------|------|
| userId + date | 升序 | 普通索引 | 查询用户日志并按日期排序 |
| userId + status | 升序 | 普通索引 | 按状态筛选日志 |
| date | 升序 | 普通索引 | 按日期范围查询 |

### 创建索引步骤
1. 在云开发控制台，选择 `logs` 集合
2. 点击「索引管理」
3. 点击「新建索引」
4. 输入索引字段和排序方式
5. 点击「确定」

## 六、权限配置详细说明

### 集合权限类型
微信云开发提供以下几种权限：
1. **仅创建者可读写** - 最常用，用户只能操作自己的数据
2. **仅创建者可读，所有人可写** - 不常用
3. **仅创建者可读写，管理端可全部读写** - 需要管理员权限
4. **所有人可读，仅创建者可读写** - 公开数据
5. **所有人可读写** - 完全公开（慎用）

### 推荐权限配置
| 集合 | 权限配置 | 说明 |
|------|-----------|------|
| users | 仅创建者可读写 | 用户只能查看和编辑自己的信息 |
| logs | 仅创建者可读写 | 用户只能查看和编辑自己的日志 |
| login_logs | 仅管理端可读写 | 登录日志只有管理员能查看 |

### 自定义权限规则
如果需要更精细的权限控制，可以使用自定义权限规则：

```json
// logs 集合的自定义权限规则
{
  "read": "doc.userId == auth.openid",
  "write": "doc.userId == auth.openid && doc.status == 'draft'"
}
// 含义：用户只能读写自己的日志，且只能编辑草稿状态的日志
```

## 八、常见问题

### Q1: 权限错误
**错误信息**：`permission denied`
**解决方法**：
1. 检查集合权限配置
2. 确认用户已登录（`wx.cloud.CloudID()` 能正确获取）
3. 检查查询条件是否超出了权限范围

### Q2: 集合不存在
**错误信息**：`collection not exists`
**解决方法**：
1. 在云开发控制台手动创建集合
2. 或通过插入数据自动创建集合

### Q3: 索引错误
**错误信息**：`index not found`
**解决方法**：
1. 在云开发控制台为集合创建索引
2. 检查查询条件是否使用了正确的索引字段
