# 施工日志小程序 - 快速测试指南

## 一、测试准备

### 1. 确认云开发环境配置

检查 `project.config.json` 中的云开发环境ID是否正确：

```json
{
  "cloudfunctionRoot": "cloudfunctions/",
  "miniprogramRoot": "miniprogram/",
  "appid": "wxd04d5e7f953c7dd0",
  "projectname": "construction-log",
  "setting": {
    // ...其他配置
  }
}
```

检查 `app.js` 中的云开发初始化代码：

```javascript
// app.js
App({
  onLaunch() {
    // 初始化云开发
    if (!wx.cloud) {
      console.error('请使用 2.2.3 或以上的基础库以使用云能力');
    } else {
      wx.cloud.init({
        env: 'cloud1-d3gnw41wh36ebbd00', // 云开发环境ID
        traceUser: true
      });
    }
    
    // 获取用户信息
    this.globalData = {};
    this.getUserInfo();
  },
  
  // ...其他代码
})
```

### 2. 上传云函数

在微信开发者工具中：
1. 点击左侧「云开发」图标
2. 在「云函数」面板中，右键点击每个云函数文件夹
3. 选择「上传并部署：云端安装依赖」

需要上传的云函数：
- login
- createLog
- getLogs
- getLogDetail
- updateLog
- deleteLog
- getWeather
- voiceToText
- exportExcel

### 3. 创建数据库集合

在云开发控制台中：
1. 点击「数据库」
2. 点击「+」号创建集合
3. 输入集合名称：`users`、`logs`、`login_logs`

### 4. 配置数据库权限

在云开发控制台中，为每个集合配置权限：

**users 集合权限**：
```json
{
  "read": "doc._openid == auth.openid",
  "write": "doc._openid == auth.openid"
}
```

**logs 集合权限**：
```json
{
  "read": "doc.userId == auth.openid",
  "write": "doc.userId == auth.openid"
}
```

**login_logs 集合权限**：
```json
{
  "read": "auth.openid == 'admin'",
  "write": true
}
```

## 二、功能测试步骤

### 测试1：用户登录

**测试步骤**：
1. 在微信开发者工具中，点击「编译」按钮运行小程序
2. 查看控制台输出，确认是否成功获取OpenID
3. 检查 `users` 集合是否自动创建了用户记录

**预期结果**：
- 控制台输出：`[登录] 成功，OpenID: xxx`
- `users` 集合中出现一条新记录

**常见问题**：
- 如果提示「云开发未开通」，请在微信开发者工具中开通云开发
- 如果提示「权限错误」，请检查集合权限配置

### 测试2：创建施工日志

**测试步骤**：
1. 在首页点击底部的「新建」Tab
2. 填写日志信息（日期、项目名称、施工内容等）
3. 点击「发布日志」按钮

**预期结果**：
- 提示「发布成功」
- 自动跳转到首页
- 首页日志列表中出现新创建的日志

**常见问题**：
- 如果提示「保存失败」，请检查云函数是否已上传
- 如果提示「权限错误」，请检查 `logs` 集合权限配置

### 测试3：查看日志列表

**测试步骤**：
1. 在首页查看日志列表
2. 测试搜索功能（输入项目名称）
3. 测试日期筛选功能

**预期结果**：
- 日志列表正常显示
- 搜索功能正常过滤日志
- 日期筛选功能正常

**常见问题**：
- 如果日志列表为空，请先创建几条测试日志
- 如果搜索功能不正常，请检查云函数 `getLogs` 的代码

### 测试4：查看日志详情

**测试步骤**：
1. 在首页点击一条日志
2. 查看日志详情页面
3. 点击「编辑」按钮
4. 修改日志信息并保存

**预期结果**：
- 日志详情页面正常显示
- 编辑功能正常
- 修改后详情页面更新

**常见问题**：
- 如果详情页面空白，请检查云函数 `getLogDetail` 是否正常
- 如果编辑后没有更新，请检查云函数 `updateLog` 是否正常

### 测试5：删除日志

**测试步骤**：
1. 在日志详情页面，点击「删除」按钮
2. 确认删除

**预期结果**：
- 提示「删除成功」
- 自动返回首页
- 首页日志列表中不再显示已删除的日志

**常见问题**：
- 如果删除失败，请检查云函数 `deleteLog` 是否正常

### 测试6：图片上传

**测试步骤**：
1. 在新建/编辑日志页面，点击「添加照片」
2. 选择一张图片
3. 保存日志

**预期结果**：
- 图片成功上传到云存储
- 图片在日志详情页面正常显示

**常见问题**：
- 如果图片上传失败，请检查云存储权限配置
- 如果图片无法显示，请检查云文件ID是否正确

### 测试7：语音输入

**测试步骤**：
1. 在新建/编辑日志页面，点击「语音」按钮
2. 开始说话
3. 点击「停止」按钮

**预期结果**：
- 语音成功识别为文字
- 文字插入到对应的输入框中

**常见问题**：
- 如果语音识别失败，请检查云函数 `voiceToText` 是否正常
- 如果识别准确率不高，可以尝试使用更清晰的语言

### 测试8：导出Excel

**测试步骤**：
1. 在首页点击「导出」按钮
2. 选择日期范围和导出格式
3. 点击「导出」按钮

**预期结果**：
- 成功生成Excel文件
- 文件自动下载或打开

**常见问题**：
- 如果导出失败，请检查云函数 `exportExcel` 是否正常
- 如果提示「exceljs模块不存在」，请在云函数目录中运行 `npm install exceljs`

## 五、常见问题与解决方法

### Q1: 云开发环境初始化失败

**错误信息**：`wx.cloud.init:fail Invalid env`

**解决方法**：
1. 检查 `app.js` 中的环境ID是否正确
2. 在微信开发者工具中，确认已选择正确的云开发环境
3. 如果环境ID正确，尝试重新开通云开发

### Q2: 云函数调用失败

**错误信息**：`cloud.callFunction:fail Error: 函数不存在`

**解决方法**：
1. 确认云函数已上传到云端
2. 确认云函数名称拼写正确
3. 在云开发控制台中查看云函数列表

### Q3: 数据库权限错误

**错误信息**：`permission denied`

**解决方法**：
1. 检查集合权限配置
2. 确认用户已登录（能正确获取OpenID）
3. 在云函数中使用管理员权限操作数据库

### Q4: 图片上传失败

**错误信息**：`uploadFile:fail Error`

**解决方法**：
1. 检查云存储权限配置
2. 确认图片文件格式正确
3. 尝试压缩图片后再上传
